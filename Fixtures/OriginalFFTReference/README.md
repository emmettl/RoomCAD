# Immutable FFT compile control

This is the exact MIT RoomCAD RealFFT source at 2bc11ed6, already independently
verified against the released shared primitive. It exists only for older numerical
reference consumers pinned to Core commits before `SpectralTransforms` existed.
Their copied AcousticCore module requires an FFT declaration even though their
wave update/control cases are a separate contract. The current application keeps
its shared alpha.17 adapter. Current FFT adoption has its complete two-host gate.

The five legacy preparation scripts bind these exact protected bytes into their
temporary verification module. Source/metadata manifests retain its Git blob,
length, SHA-256 and compressed identity. Pins, goldens, case identities, updates,
geometry and numerical assertions remain unchanged. No reference source is restored
in production. The copier rejects any destination within the real Sources tree.
